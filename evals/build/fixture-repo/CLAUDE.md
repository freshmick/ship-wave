# tripsheet

A small library: plain JavaScript modules in `src/`, tests in `test/` on Node's built-in runner. No dependencies.

## Checks
- `npm test` runs every test. It is the only check, and CI runs the same command.

## Conventions
- The default branch is `main`. Merge by squash and delete the branch.
- Keep the README's API section true when a function's behaviour changes.

## Issues
- Issues are GitHub Issues in this repository; use `gh`.
- Labels: `ready-for-agent` marks an issue an agent may start.
